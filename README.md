# CakePHP AiInteraction Plugin

The **AiInteraction** plugin provides UI-agnostic interaction contracts for AI agents in CakePHP applications.

Use it to dispatch slash commands, run turns, manage sessions and conversations, recall inputs with history, store per-user preferences, generate session titles from terminal hosts via `crustum/ai-tui` and web hosts via the command interceptor.

## Requirements

* PHP 8.4+
* crustum/cakephp-ai

See [Versions.md](docs/Versions.md) for the supported CakePHP versions.
